# Security Policy

## Supported Versions

Latest release(or master branch) only.  
KO) 최신 릴리즈(혹은 master branch)의 취약점만 검토합니다.  

## Reporting a Vulnerability

Please mail to waterticket@potatosoft.kr  
Do not open github public issues related to security problems.  

KO) waterticket@potatosoft.kr 로 메일을 전송해주세요.  
Github issue로 제보하지 말아주세요.
